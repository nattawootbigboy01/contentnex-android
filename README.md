# CONTENTNEX

**Your AI-Powered Content Business Studio**

Native Android workspace for online sellers. The first milestone provides an offline-first content drafting experience.

## Included
- Kotlin + Jetpack Compose Android app
- Thai-first dashboard, caption writer, and weekly content planner
- Local template-based caption drafting and clipboard copy
- GitHub Actions workflow to build and upload a debug APK

## Transparency
The initial writer uses local templates. It is not connected to GPT, Gemini, or another generative AI model. No paid API, billing, card, or secret key is required.

## Build
GitHub Actions installs Android SDK and Gradle on its hosted runner and runs `gradle assembleDebug`.

Package: `com.contentnex.app`
